تحلیل بیزنسی بدون هوش مصنوعی هم کامل ساخته می‌شود (با قواعد، کاملاً آفلاین). با «غنی‌سازی با Claude» فقط ساختار — نام جدول‌ها و ستون‌ها، نوع داده، کلیدها و توضیحات ثبت‌شده — به Anthropic ارسال می‌شود، نه داده‌ها. هزینه تقریبی ۱ تا ۳ سنت به ازای هر جدول (مدل Claude Opus 5.5) است و مقدار واقعی در گزارش کار نمایش داده می‌شود. کلید فقط در Windows Credential Manager ذخیره می‌شود.

ساخت Word به Microsoft Word و Chrome یا Edge روی همین کامپیوتر نیاز دارد. اگر فایل‌های امروز از قبل وجود داشته باشند، بازنویسی نمی‌شوند و انتشار متوقف می‌شود.
